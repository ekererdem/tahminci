# Tahminci

Futbol maç simülasyonu (Dixon-Coles + Monte Carlo) ve Bilyoner canlı oran karşılaştırması.

- APK: [Tahminci.apk](https://github.com/ekererdem/tahminci/releases/download/latest/Tahminci.apk)
- Takım güçleri her gün `model/build_ratings.py` ile football-data.co.uk verisinden hesaplanır ve `veri` sürümüne yüklenir.
